## `02` — Selected Projects

### ◈ Home SOC Lab
**Wazuh SIEM · Sysmon · Windows · Kali Linux · MITRE ATT&CK**

A hands-on environment for exploring how security events emerge, how endpoint activity can be investigated, and how detection logic supports defensive operations.

- Built a virtual SOC lab to simulate attack activity and investigate security events.
- Examined process activity, endpoint telemetry, network connections, and authentication logs.
- Simulated Nmap scanning and SMB brute-force activity in a controlled lab environment.
- Used Windows Event IDs and Sysmon logs to investigate activity and map observed behaviors to MITRE ATT&CK.
- Developed custom detection rules and documented findings with indicators of compromise (IOCs) and remediation recommendations.

**Key takeaway:** Connecting observable system behavior with detection logic and actionable investigation reports.

### ◈ VulnScanX — Web Vulnerability Scanner
**Python · SQLite · Web Security · Automated Reporting**

A modular security-testing project designed to identify common web application weaknesses and turn scan results into useful remediation guidance.

- Implemented checks for SQL injection, cross-site scripting (XSS), and missing HTTP security headers.
- Developed session-based authentication support and automated HTML form discovery.
- Used the OWASP WebGoat training environment for application security testing.
- Stored scan results in SQLite and generated Markdown reports with severity ratings and remediation guidance.

**Key takeaway:** Making vulnerability assessment more structured, repeatable, and useful for remediation.
